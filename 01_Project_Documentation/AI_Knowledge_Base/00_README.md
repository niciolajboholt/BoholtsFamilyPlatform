# Formål

AI Knowledge Base er projektets centrale vidensbase.

Dokumentationen skal sikre, at både mennesker og AI-agenter kan forstå projektets historie, arkitektur, beslutninger, arbejdsmetoder og fremtidige retning uden at skulle læse tidligere chats eller gennemgå hele Git-historikken.

Knowledge Base fungerer som projektets langsigtede hukommelse.

---

# Mål

Knowledge Base skal:

- dokumentere projektets udvikling
- beskrive arkitekturen
- forklare de vigtigste designbeslutninger
- fastholde erfaringer
- beskrive udviklingsstandarder
- gøre onboarding af nye udviklere og AI-agenter hurtig
- sikre kontinuitet gennem hele projektets levetid

# Vedligeholdelse

Knowledge Base er et levende dokument.

Alle større ændringer i arkitektur, udviklingsproces eller projektretning skal afspejles her.

Ved afslutningen af større sprint bør dokumentationen opdateres.

---

# Principper

Dokumentationen skal være:

- præcis
- teknisk korrekt
- let at læse
- versionsstyret
- AI-venlig
- fremtidssikret

Den skal beskrive både beslutninger og begrundelser.

---

# Sammenhæng med øvrig dokumentation

AI Knowledge Base erstatter ikke PRD'er, ADR'er eller teknisk dokumentation.

Den binder dokumentationen sammen og beskriver den viden, der normalt kun eksisterer i udviklernes hukommelse.
