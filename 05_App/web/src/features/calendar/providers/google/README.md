# Google Calendar-provider

Denne mappe er reserveret til en senere `GoogleCalendarProvider`, som skal
implementere `CalendarProvider`-kontrakten fra den overordnede providers-mappe.

Sprint 10.1 indeholder bevidst ingen Google API-kald, OAuth, tokens,
miljøvariabler eller demo-data. En senere implementation skal oversætte
Google-modeller og fejl til kalenderens leverandøruafhængige domænetyper, før
data når hooks eller UI.
